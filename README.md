# Smart Internship Tracker

## Overview

Smart Internship Tracker is a Python and SQLite-based application designed to help students manage and track their internship applications.

The application allows users to add, view, update, delete, search, and export internship applications while also providing application statistics.

This project was built to strengthen my Python, SQL, and database management skills through a practical real-world use case.

## Features

- Add internship applications
- View all applications
- Update application status
- Delete applications
- Search applications by company name
- View application statistics
- Export applications to CSV
- Input validation for status fields

## Technologies Used

- Python
- SQLite3
- CSV Module
