# Smart Internship Tracker Pro

## Overview

Smart Internship Tracker Pro is a Python-based application designed to help students manage and track their internship applications efficiently.

The project allows users to add, view, update, delete, search, and export internship applications while also providing statistics and visual insights through an interactive Streamlit dashboard.

This project was built to strengthen my Python, SQL, database management, and data visualization skills through a practical real-world use case.

---

## Features

- Add internship applications
- View all applications
- Update application status
- Delete applications
- Search applications by company name
- View application statistics
- Export applications to CSV
- Interactive Streamlit dashboard
- Visual analytics using charts
- Input validation for user entries
